# Padma Velan M — Static Portfolio

A responsive personal portfolio built with only HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and colors inspired by the supplied resume (white, charcoal, muted teal, and soft grey)
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser. No build tools or frameworks are required.

## Before publishing
Check the contact details and institution names for accuracy. The page uses Google Fonts via an external import; the site still falls back to system fonts if those fonts cannot load.
